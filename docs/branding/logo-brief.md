# Logo and Visual Identity Brief

## Brand Name
BAPI - Benue AgriPrice Insight

## Brand Positioning
BAPI should feel like a premium but grounded agricultural intelligence system. The identity must express trust, calmness, modernity, and local relevance while visually combining the warmth of nature with structured analytical insight.

## Core Visual Message
- agriculture
- insight
- structure
- trust
- local market intelligence

## Logo Requirements
### Wordmark
- Use `BAPI` as the main visible name.
- Typography should be large, bold, and highly legible.
- A refined serif or elegant display style is preferred so long as readability remains excellent at header and mobile sizes.

### Icon Direction
- Integrate a stylized leaf or sprouting plant with the `B` or place it closely beside or above the wordmark.
- The icon should subtly echo both farm-field geometry and forest softness.
- A faint upward directional cue may be integrated if it remains subtle.

### Supporting Motifs
- Very faint grid motif or calm horizontal lines may appear under or around the logo.
- These should suggest data structure and farmland plots without looking busy.

## Color Rules
- Evergreen: `#0F3A2F`
- Jade: `#34C9A2`
- Mint: `#A1E8C8`
- Background: `#F8F7F2`

### Required Color Usage
- Main `BAPI` text in Evergreen
- One accent letter, preferably `A` or `I`, in Jade
- Leaf or plant icon uses a gradient from Evergreen to Jade to Mint
- No neon tones
- No harsh glow effects

## Required Logo Variations
- Primary horizontal version
- Stacked version
- Icon-only version
- Monochrome version

## Usage Rules
- The logo must work on the project's cream background with subtle grid lines.
- It must remain readable in navbar-sized placement and in small report-cover placement.
- The icon-only version must be clear enough for favicon or app-icon use.

## Background Treatment Rule
The preferred page background is:
- soft cream base
- low-opacity grid lines
- gentle evergreen and mint gradient atmosphere

The logo must remain clear on this treatment without needing heavy outlines or dark boxes.

## Tone to Avoid
- flashy tech startup aesthetics
- generic farming clip-art
- neon gradients
- overly playful or cartoon-like presentation

- monochrome light-background version
