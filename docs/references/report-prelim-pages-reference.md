# Report Prelim Pages Reference

## Purpose
This file explains the manual follow-up needed for report preliminary pages that require personal, institutional, or approval details.

## Documents Covered
- `docs/academic/report-title-page.md`
- `docs/academic/certification-page.md`
- `docs/academic/dedication.md`
- `docs/academic/acknowledgement.md`
- `docs/academic/abstract.md`

## Manual Steps
1. Replace every bracketed placeholder with your actual details.
2. Confirm your school's exact title-page and certification format.
3. Insert real supervisor and HOD names only in your final submission version.
4. Adjust the abstract after implementation so it reflects final results.
5. Remove any prelim page your department does not require.

## Placeholder Acceptability
- Placeholder versions are acceptable inside the repo while planning and drafting.
- Final submission copies must use the correct institutional format and real details.
