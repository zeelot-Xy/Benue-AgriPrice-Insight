# Logo Reference Notes

## Purpose
This file records what still needs to be done outside Markdown to produce the final BAPI logo assets.

## Asset Still Needed
- Final horizontal logo
- Final stacked logo
- Final icon-only logo
- Final monochrome variants
- Exported SVG and PNG files

## Where It Belongs
- App navbar and dashboard header
- Login page
- Favicon or app icon
- Final report cover
- Presentation slides

## Manual Steps
1. Create the BAPI logo using the rules in `docs/branding/logo-brief.md`.
2. Export all required variants in SVG and PNG.
3. Save the chosen asset filenames and placement notes in this file.
4. Update the frontend later to use the final approved assets.

## Placeholder Acceptability
- For planning and early development, the logo may remain as a text placeholder.
- For the final report, final presentation, and polished application, the placeholder should be replaced.
