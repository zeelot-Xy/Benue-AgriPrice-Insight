# Submission Readiness Checklist

## Purpose
This checklist summarizes what must be complete before final academic submission, report printing, presentation, and defense.

## Report Content
- Title page details confirmed
- Certification page updated with department-approved wording
- Dedication finalized or removed if not required
- Acknowledgement personalized
- Abstract updated to reflect final implementation
- Chapter One written and aligned with the approved scope
- Chapter Two completed with real academic citations
- Chapter Three aligned with requirements, architecture, and ERD
- Chapter Four aligned with implementation and screenshots
- Chapter Five aligned with testing results, conclusions, and recommendations

## Diagrams and Visuals
- Use-case diagram polished
- System architecture diagram polished
- ERD polished
- Final BAPI logo assets prepared
- Dashboard screenshots captured
- Analytics screenshots captured
- Upload screenshots captured
- Admin screenshots captured
- Login screenshot captured

## Runtime Readiness
- `.env` created from `.env.example`
- Docker Desktop running
- PostgreSQL available
- API starts successfully
- Frontend starts successfully
- `npm run smoke:check` passes or known exceptions are documented

## Defense Readiness
- Demo flow rehearsed
- Backup screenshots prepared
- Defense evidence matrix reviewed
- Supervisor meeting log updated
- Manual action tracker reviewed one final time
