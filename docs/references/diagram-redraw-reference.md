# Diagram Redraw Reference

## Purpose
This file tracks diagrams that currently exist in Mermaid or Markdown form but may later need polished exported visuals for the final report or defense slides.

## Candidate Diagrams
- Use case diagram in `docs/academic/use-case-model.md`
- System architecture diagram in `docs/architecture/system-architecture.md`
- ER diagram in `docs/architecture/erd.md`
- Data flow diagram in `docs/architecture/data-flow-and-analysis-rules.md`

## Manual Steps
1. Decide whether your department accepts Mermaid-rendered diagrams directly.
2. If not, recreate or export each listed diagram using a clean diagram tool.
3. Preserve the same relationships and wording so the redrawn version matches the repo source.
4. Insert the final images into the report document you submit outside this repo if needed.

## Placeholder Acceptability
- Mermaid diagrams are acceptable for repo documentation and early supervision.
- Polished image-based diagrams are usually better for final report printing and defense slides.
