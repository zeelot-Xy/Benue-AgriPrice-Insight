# Abstract

This project presents the design and implementation of BAPI, a web-based agricultural market price monitoring and analysis system for Benue State. The system focuses on four representative markets, namely Makurdi, Gboko, Zaki Biam, and Otukpo, and monitors eight major commodities: Yam, Cassava, Rice, Maize, Beans, Soybean, Millet, and Sorghum.

The motivation for the study is the limited availability of structured and comparable agricultural market price information for local stakeholders such as farmers, traders, and policymakers. To address this problem, the system was designed to support historical data storage, weekly price updates, dashboard visualization, market comparison, state-average calculation, explainable trend detection, alert generation, and moderated public data contribution.

The project adopts a full-stack architecture using React and TypeScript on the frontend, Express and TypeScript on the backend, Prisma ORM for database access, and PostgreSQL for persistent storage. The system emphasizes explainability by prioritizing deterministic rule-based analysis and clear moderation workflows so that both analytics and data-quality decisions can be defended in plain language.

The completed outcome is a maintainable and academically defensible web platform that improves visibility into agricultural market price behavior within the selected Benue State markets while keeping the system understandable, testable, and locally runnable.

**Keywords:** agricultural market prices, Benue State, price monitoring, web-based system, explainable analytics, market comparison
