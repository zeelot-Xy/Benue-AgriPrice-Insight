# Abstract

This project presents the design and implementation of BAPI, a web-based agricultural market price monitoring and analysis system for Benue State. The system focuses on four representative markets, namely Makurdi, Gboko, Zaki Biam, and Otukpo, and monitors eight major commodities: Yam, Cassava, Rice, Maize, Beans, Soybean, Millet, and Sorghum.

The motivation for the study is the limited availability of structured and comparable agricultural market price information for local stakeholders such as farmers, traders, and policymakers. To address this problem, the system was designed to support historical data storage, weekly price updates, dashboard visualization, market comparison, state-average calculation, explainable trend detection, and price alerts. An optional forecasting layer is also proposed through a separate machine learning microservice.

The project adopts a full-stack architecture using React and TypeScript on the frontend, Express and TypeScript on the backend, PostgreSQL for data storage, and FastAPI for forecasting support. The system emphasizes explainability by prioritizing deterministic rule-based analysis before machine learning enhancement.

The expected outcome is a maintainable and academically defensible web platform that improves visibility into agricultural market price behavior within the selected Benue State markets.

**Keywords:** agricultural market prices, Benue State, price monitoring, web-based system, explainable analytics, forecasting
