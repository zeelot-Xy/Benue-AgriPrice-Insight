# Phase Roadmap

## Ordered Delivery Plan
1. Phase 0: Project definition, academic framing, and repo setup
2. Phase 1: Requirements analysis, system design, ERD, and architecture
3. Phase 2: Dataset strategy and data preparation
4. Phase 3: Git workflow discipline and monorepo structure refinement
5. Phase 4: Local environment setup
6. Phase 5: Database modeling with Prisma schema
7. Phase 6: Backend API development
8. Phase 7: Rule-based analysis engine
9. Phase 8: ML layer with FastAPI and forecasting
10. Phase 9: Frontend UI implementation
11. Phase 10: Frontend-backend integration
12. Phase 11: Testing, edge cases, and debugging
13. Phase 12: Documentation and academic mapping
14. Phase 13: Final polishing and defense preparation

## Delivery Principle
Each phase must finish with:
- a clear objective
- bounded files and folders
- verification steps
- edge-case considerations
- academic defense notes

## Governance Rule
Do not begin a new major phase until the current phase is complete and reviewed.
