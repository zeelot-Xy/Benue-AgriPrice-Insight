# Scope and Constraints

## Purpose
This document defines the exact operational boundary of the project.

## In Scope
- Benue State only
- Four markets: Makurdi, Gboko, Zaki Biam, Otukpo
- Eight commodities: Yam, Cassava, Rice, Maize, Beans, Soybean, Millet, Sorghum
- Historical records and weekly price monitoring
- Admin management of official records
- Public submission through a moderated review workflow
- Rule-based analysis: trends, alerts, seasonality summaries, market comparisons, and state averages

## Out of Scope
- Real-time scraping
- IoT devices
- Mobile app development
- Expansion beyond the selected four markets
- Expansion beyond the selected eight commodities
- Machine-learning forecasting in the final implementation baseline

## Constraint Rationale
- A narrower scope improves feasibility.
- Explainable analytics are easier to defend than speculative complexity.
- Moderated submission is safer than direct public publishing.
