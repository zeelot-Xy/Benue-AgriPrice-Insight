# Scope and Constraints

## Geographic Scope
Benue State, Nigeria

## Representative Markets
- Makurdi
- Gboko
- Zaki Biam
- Otukpo

## Selected Commodities
- Yam
- Cassava
- Rice
- Maize
- Beans
- Soybean
- Millet
- Sorghum

## Functional Scope
- Admin authentication
- Manual weekly price entry
- CSV import for historical and weekly data
- Commodity and market management
- Dashboard visualization
- Trend summaries
- Price alerts
- Seasonality insights
- State average calculations
- Market-to-market comparison
- Optional forecasting outputs

## Non-Functional Scope
- Maintainable monorepo structure
- Strong typing with TypeScript
- Explainable service-layer business logic
- Secure API basics with JWT and Helmet
- Simple local deployment via Docker Compose

## Hard Constraints
- No real-time data scraping
- No IoT sensors
- No mobile app
- No uncontrolled AI decisions
- No opaque recommendation engine
- No expansion beyond the approved four markets and eight commodities

## Academic Defense Position
The restricted scope is intentional. It improves data quality control, technical explainability, feasibility, and the probability of completing a robust final-year project rather than a broad but weak prototype.
