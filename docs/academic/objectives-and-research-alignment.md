# Objectives and Research Alignment

## Research Motivation
Agricultural markets function better when participants can observe price behavior across places and time. In many local settings, this information is not systematically recorded in a form that is easy to compare, interpret, or analyze. This project responds to that gap by building a scoped decision-support system that converts agricultural price records into meaningful monitoring and analysis outputs.

## Main Aim
To design and implement a web-based agricultural market price monitoring and analysis system for Benue State.

## Specific Objectives
1. Develop a system for collecting and storing historical and weekly commodity prices.
2. Support accurate and manageable data entry using manual forms and CSV import.
3. Provide dashboards for time-series visualization and cross-market comparison.
4. Generate explainable rule-based insights such as price direction, alerts, and seasonal observations.
5. Integrate optional short-term forecasting for selected commodity-market series.
6. Deliver a system that is technically maintainable and academically defendable.

## Research Questions
1. How can historical and weekly agricultural market prices from selected Benue markets be organized into a usable web-based monitoring platform?
2. Which explainable analytical rules can help users interpret price movement patterns?
3. How can forecasting be introduced without making the system dependent on opaque or unjustified machine learning output?

## Academic Relevance
This project contributes to:
- agricultural informatics
- applied software engineering
- local decision-support system design
- explainable analytics in resource-constrained academic projects

## Methodological Alignment
The project aligns with a practical design-and-implementation research approach:
- identify a local information problem
- define strict scope boundaries
- design a layered software architecture
- implement monitoring features first
- add explainable analysis
- evaluate optional forecasting as an enhancement

## Why Rule-Based Analysis Comes Before ML
Rule-based analysis is the correct first analytical layer for this project because:
- it is transparent and easy to defend
- it delivers useful insights with limited data
- it avoids dependence on large or perfect datasets
- it creates a baseline against which forecasting can later be evaluated

## Expected Contribution
- A scoped agricultural market price intelligence system for Benue State
- A maintainable full-stack architecture with separate data, analytics, and forecasting layers
- A demonstration that practical insight can be delivered through explainable rules before advanced ML is added

## Evaluation Orientation
The project should be evaluated according to:
- correctness of data management
- usefulness of dashboards and comparisons
- clarity of analytical explanations
- feasibility and maintainability of implementation
- academic coherence between problem, design, and implementation
