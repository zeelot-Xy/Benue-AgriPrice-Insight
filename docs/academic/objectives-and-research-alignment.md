# Objectives and Research Alignment

## Research Motivation
Farmers and traders often need clearer visibility into price movements across local markets. A focused monitoring and analysis platform can reduce information asymmetry and improve decision quality.

## Core Research Questions
1. How can agricultural market prices from selected Benue State markets be organized into a usable web-based monitoring system?
2. What explainable analytical techniques can help users understand price movement patterns over time?
3. Can short-term forecasting improve insight quality without reducing explainability or academic defensibility?

## Research Relevance
- Supports agricultural informatics
- Demonstrates applied data engineering and web systems design
- Connects software engineering to local economic decision support

## Technical Justification
- Web-based architecture supports broad accessibility for stakeholders.
- Rule-based analysis provides immediate value before machine learning is introduced.
- Optional forecasting adds academic depth without making the system dependent on black-box logic.

## Expected Academic Contributions
- A scoped domain-specific market intelligence system for Benue State
- A defendable full-stack architecture using modern engineering practices
- An explainable blend of descriptive analytics and optional forecasting
