# Objectives and Research Alignment

## Purpose
This document aligns the practical system objectives with defensible academic research questions.

## Project Objectives
1. Build a secure web-based system for managing agricultural market price information in Benue State.
2. Store and visualize historical and weekly prices for the approved markets and commodities.
3. Provide explainable analysis through trends, alerts, seasonality summaries, market comparisons, and state averages.
4. Support moderated public submission of price observations.
5. Maintain a system that is feasible, understandable, and academically defendable.

## Research Questions
1. How can a web-based system improve access to structured agricultural market price information for selected markets in Benue State?
2. How can explainable rule-based analytics support understanding of market behavior without relying on opaque automated decisions?
3. How can public contribution be supported without allowing unverified data to distort the official outputs of the system?

## Academic Significance
- The project addresses a real local information problem.
- It demonstrates applied software engineering in a clearly bounded domain.
- It shows that useful analytical value can be achieved without overcomplicating the architecture.

## Expected Contribution
- A maintainable full-stack architecture with clear frontend and backend separation
- A practical monitoring and analysis platform for selected Benue State markets
- A moderated contribution workflow that balances usability with data quality
