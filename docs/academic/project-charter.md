# Project Charter

## Project Name
BAPI - Benue AgriPrice Insight

## Official Project Title
Design and Implementation of a Web-Based Agricultural Market Price Monitoring and Analysis System for Benue State

## Background
Agricultural commodity prices in Benue State vary across markets and time periods, yet farmers, traders, and public-sector planners often rely on fragmented or informal information when making decisions. This can lead to poor market timing, weak bargaining power, reduced profitability, and ineffective policy response.

## Problem Statement
There is no focused, explainable, and academically appropriate web-based system dedicated to monitoring and analyzing the prices of selected agricultural commodities across representative markets in Benue State using structured historical and weekly price records.

## Aim
To design and implement a web-based agricultural market price monitoring and analysis system for Benue State that supports weekly data capture, historical analysis, visualization, comparison across markets, and explainable price forecasting.

## Objectives
1. Design a secure web platform for managing agricultural commodity price data.
2. Capture and store historical and weekly market prices for selected commodities in selected Benue markets.
3. Provide dashboards for market comparison, state averages, and trend visualization.
4. Implement rule-based analysis for price changes, alerts, and seasonal insight generation.
5. Provide an optional machine learning forecasting component for short-term price prediction.
6. Present results in a way that is understandable to farmers, traders, and policymakers.

## In-Scope Entities
- Markets: Makurdi, Gboko, Zaki Biam, Otukpo
- Commodities: Yam, Cassava, Rice, Maize, Beans, Soybean, Millet, Sorghum
- Roles: Admin, Viewer/Farmer

## Out of Scope
- Real-time web scraping
- IoT-based market sensors
- Mobile application development
- Nationwide or multi-state coverage
- Fully autonomous data acquisition

## Expected Outcome
A complete demo-ready web-based system with clear academic justification, practical usefulness, explainable analysis, and defendable implementation choices.

## Success Criteria
- The project remains within scope and can be completed on time.
- The system works end-to-end without requiring AI/ML to be useful.
- Analysis outputs are interpretable and supported by stored data.
- The forecasting component, if enabled, is clearly separated and explainable.
